    VaultScan — 12 Security Vectors Reference

    VaultScan inspects tokens against standard RFC 7519 requirements and MITRE ATT&CK techniques:

    1. alg: none (CRITICAL, MITRE T1550.001) — Token unsigned; permits arbitrary claim forgery.
    2. Weak HS256 secret (CRITICAL, MITRE T1110.002) — Passphrase crackable via offline dictionary search.
    3. Algorithm confusion (HIGH, MITRE T1550.001) — Asymmetric verification confounded with symmetric HMAC.
    4. Missing exp claim (HIGH) — Token never expires; permanent replay vulnerability.
    5. Expired token (MEDIUM) — Session elapsed; verifier must reject expired state.
    6. Excessive expiry (MEDIUM) — Token lifetime exceeds 24 hours without rotation.
    7. Sensitive payload data (HIGH, MITRE T1552.001) — Plaintext credentials or PII readable in Base64URL.
    8. Missing iss claim (LOW) — Issuer authority unspecified.
    9. Missing aud claim (LOW) — Audience target service unspecified.
    10. kid path traversal (HIGH, MITRE T1083) — Directory traversal sequences in key ID.
    11. Large token size (LOW) — Token length exceeds 4,096 bytes; HTTP 431 risk.
    12. External jku/x5u URL (HIGH, MITRE T1195) — Remote JWKS endpoint pointing to untrusted hosts.
